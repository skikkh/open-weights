# API料金比較の追加（2026-11-12）

有料側の上部ナビに「API料金比較」を追加した。対象はテキストLLMの31モデル・79料金経路、13の開発会社。開発会社別、同じモデルの提供元別、用途のクラス別、API提供会社別に切り替えられる。通常料金では利用可能な28モデル・58経路を表示し、他の課金方式や限定・会員提供を分けた。

## 比較と試算の条件

入力・出力・キャッシュ読込を、原通貨の100万トークン単価に統一した。同じトークン数・月間回数を入力して1回と月間のトークン料を試算する。文字数からの推定は行わず、思考トークンを出力数に含めるよう表示する。

試算の範囲は通常入力＋キャッシュ読込＋出力。キャッシュ書込・保管、検索・ツール、税、入金手数料は除外し、画面に明記した。書込単価を確認できた場合は保持時間とともに条件欄に掲載する。不明を0円として計算しない。キャッシュ単価不明の経路で命中率を指定した場合は見積もりを出さない。

原通貨はUSD・JPY・CNY。原通貨で料金順を選んだ場合は通貨ごとに並べる。換算は利用者が入力した円基準レートを使い、レート不明の通貨を数値順位に混ぜない。為替の最新値を自動取得したとは表示しない。

比較クラスは用途・提供元の位置付けをもとにした編集上の分類であり、性能の同等性を保証しない。別のAPI提供元では精度、量子化、速度、地域、データ利用・保持条件が変わり得る。OpenRouterの経路は直販と区別し、各経路の量子化・課金方式・タグを保持する。
